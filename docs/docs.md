# 引言
尽管视觉语言模型（VLM）在感知上取得了巨大进展，并被广泛用于语言引导的机器人，但它们在理解空间指令时常常在关键问题上“卡壳”：如何处理空间的不确定性。想象一下，你让VLM“找到那个青色碗旁边的空位”。
现有的主流方法（基于点或边界框）难以胜任。这些离散表示无法捕捉由空间关系定义的复杂、非矩形区域，如下图所示。将这种模糊区域压缩为点或边界框会造成严重的信息瓶颈，使机器人系统变得脆弱且难以解释。

<p align="center"><img src="images/teaser-2.jpg" alt="teaser" width="75%"></p>

为了解决这一难题，来自清华大学和华为诺亚方舟实验室的研究人员提出了RoboMAP框架，RoboMAP不再输出离散的点，而是生成一种“自适应可供性热力图”。这种密集的热力图将整个观测空间建模为一个连续的概率分布，能动态地适应指令的模糊性：对于精确的目标，它会形成一个尖锐的峰值；而对于模糊的指令，它则会形成一个广泛分布的区域。

这种创新的表示方式，使机器人能够显式地捕捉和理解复杂的空间概念，从而显著提高在现实世界复杂任务中的成功率和鲁棒性。同时，该框架的推理速度比先进的基线模型快50倍以上，推理时间仅为0.04秒，使机器人实时推理成为可能。

# 方法
![overall](images/overall.jpg)
为实现这一目标，RoboMAP 在视觉语言骨干网络之后引入了一个新颖的“自适应热力图解码器”（AHD）。该解码器采用内容感知上采样机制，通过“自适应核生成器”（AKG）和“粗略情景预测器”（CAP）两个分支协同工作。这使其能够根据指令的模糊程度动态调整生成热力图的形状——对精确指令生成尖锐峰值，对模糊指令则生成更广泛的分布。

在训练方面，为解决缺乏密集热力图标注数据的问题，研究团队提出了一种“程序化真值热力图合成”流程。该流程能将不同来源的稀疏标注（如关键点、边界框和机器人轨迹）统一转换为密集、一致的自适应热力图作为监督信号。这种数据高效的方法使得模型能利用多样化的数据进行跨域学习，并通过像素级损失函数进行优化。
